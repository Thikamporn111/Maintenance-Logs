## 0. เตรียมก่อนเริ่ม

สร้างบัญชีทดสอบใน Supabase → Authentication → Users แล้วกำหนด role ในตาราง `profiles` ให้ครบ 3 บทบาท

- [x] บัญชี role `admin`
- [x] บัญชี role `technician`
- [x] บัญชี role `viewer`

## 1. สิทธิ์การเข้าถึง (RBAC) — โจทย์ข้อ 3.1

สิทธิ์ที่ระบบกำหนดไว้ (อ้างอิง `src/lib/domain/permissions.ts`)

| Role | หน้าที่เข้าได้ | สิทธิ์ |
|---|---|---|
| admin | ทุกหน้า | ทุกอย่าง รวม Users และ Audit Log |
| technician | Dashboard, Machines, Alarms, Maintenance, Plan | สร้าง/ปิด Alarm, งานซ่อม, ออกใบงาน PM (แก้ข้อมูลเครื่องจักรไม่ได้) |
| viewer | Dashboard เท่านั้น | ดูอย่างเดียว |

ทดสอบโดย **พิมพ์ URL ตรง ๆ** ไม่ใช่แค่ดูว่าเมนูถูกซ่อน เพราะต้องพิสูจน์ว่าตรวจสิทธิ์ที่ server

- [x] viewer: เมนูเหลือแค่ Dashboard
- [x] viewer เปิด `/machines` ตรง ๆ → ถูกปฏิเสธ (403)
- [x] viewer เปิด `/users` ตรง ๆ → ถูกปฏิเสธ (403)
- [x] viewer เปิด `/audit` ตรง ๆ → ถูกปฏิเสธ (403)
- [x] technician เปิด `/users` ตรง ๆ → ถูกปฏิเสธ (403)
- [x] technician เปิดหน้า Machines ได้ แต่เพิ่ม/แก้ไขเครื่องจักรไม่ได้
- [x] ไม่ได้ล็อกอิน เปิด `/dashboard` → เด้งไปหน้า Login
- [x] Logout แล้วกดปุ่ม Back ของเบราว์เซอร์ → กลับเข้าระบบไม่ได้

## 2. Validation — โจทย์ข้อ 3.7

กรอกผิดต้องขึ้นข้อความเตือน ไม่ใช่บันทึกผ่าน (อ้างอิง `src/lib/domain/validation.ts`)

| ช่อง | ใส่ค่าผิด | ผลที่ถูกต้อง | ผ่าน |
|---|---|---|---|
| Machine ID | `M1`, `abc`, `M-1` | ต้องเป็นรูปแบบ `M-001` | [x] |
| Alarm Code | `123`, `E1` | ต้องเป็นรูปแบบ `E-201` | [x] |
| เวลาเกิด Alarm | เลือกวันพรุ่งนี้ | "เวลาเกิดต้องไม่อยู่ในอนาคต" | [x] |
| ช่องบังคับทั้งหมด | เว้นว่าง แล้วกดบันทึก | เตือนครบทุกช่อง | [x] |
| รหัสผ่าน (เพิ่ม User) | ใส่ 3 ตัวอักษร | ต้องมีอย่างน้อย 6 ตัวอักษร | [x] |
| อีเมล | `abc@`, `abc` | รูปแบบอีเมลไม่ถูกต้อง | [x] |
| Role ID | `ADMIN`, `admin!` | ใช้ได้เฉพาะ a-z, 0-9, `-`, `_` | [x] |

## 3. CRUD ครบวงจร — โจทย์ข้อ 3.2 – 3.4

ทำครบทุกขั้นในแต่ละหน้า: เพิ่ม → เห็นในตาราง → แก้ไข → ค่าเปลี่ยนจริง → ลบ → หายไป → **กด F5 แล้วข้อมูลยังอยู่**

ข้อสุดท้ายสำคัญที่สุด เพราะพิสูจน์ว่าบันทึกลง Supabase จริง ไม่ได้อยู่แค่ในหน้าจอ

- [x] Machines
- [x] Alarms
- [x] Maintenance
- [x] Maintenance Plan (PM)
- [x] Users & Roles (admin เท่านั้น)

## 4. ค้นหาและกรอง — โจทย์ข้อ 3.5

- [x] กรองหลายเงื่อนไขพร้อมกัน (สถานะ + ช่วงวันที่ + คำค้น)
- [x] ก๊อป URL หลังกรอง ไปเปิดแท็บใหม่ → ได้ผลกรองเดิม
- [x] ค้นคำที่ไม่มีในระบบ → ขึ้น "ไม่พบข้อมูล" ไม่ใช่หน้าเปล่าหรือ error

## 5. Dashboard — โจทย์ข้อ 3.6

- [x] ตัวเลขการ์ดสรุปตรงกับจำนวนจริงในตาราง
- [x] เพิ่ม Alarm ใหม่ 1 รายการ แล้วกลับมาดู ตัวเลขเพิ่มตาม
- [x] กราฟ 7 วันมีข้อมูล ไม่ใช่กราฟเปล่า
- [x] สถานะแผน PM (เกินกำหนด / ครบใน 7 วัน) แสดงถูกต้อง

- [x] ทำรายการใด ๆ (เช่น เพิ่มเครื่องจักร) แล้วมีบันทึกใน Audit Log ว่าใคร ทำอะไร เมื่อไหร่
- [x] เฉพาะ admin เท่านั้นที่เปิดหน้านี้ได้

## 7. UI และรายละเอียดปลีกย่อย

- [x] สลับภาษา TH / EN ครบทุกหน้า ไม่มีคำที่แปลไม่ครบ
- [x] Dark mode อ่านออกทุกหน้า ไม่มีตัวอักษรกลืนพื้นหลัง
- [x] เปิดบนมือถือ: ตารางเลื่อนดูได้ เมนูกดได้ ไม่ล้นจอ
- [x] เวลาที่แสดงเป็นเวลาไทย (UTC+7) ไม่ใช่เวลาเซิร์ฟเวอร์
- [x] เปิด URL ที่ไม่มีจริง เช่น `/machines/M-999` → ขึ้นหน้า 404 ปกติ ไม่ใช่ error ดิบ

## 8. ทดสอบบน Production โดยเฉพาะ

- [x] เปิดจากเน็ตมือถือ (ไม่ใช่ WiFi เครื่องที่พัฒนา) เข้าได้ปกติ
- [x] ล็อกอิน Google จากเครื่องที่ไม่เคยใช้มาก่อน สำเร็จ
- [x] ล็อกอินแล้วไม่เด้งกลับไป `localhost` (ต้องตั้ง Site URL ใน Supabase ให้ถูก)
- [x] เปิด 2 เบราว์เซอร์คนละบัญชีพร้อมกัน ข้อมูลไม่ปนกัน
